Acceder con Google

Tu colección se guarda en tu Google Drive

⚠️ Abre la app desde http://localhost

Google no permite iniciar sesión con el archivo abierto como file://. Sirve la carpeta y entra por HTTP:

python -m http.server 8000

✓ Google configurado

ID de cliente:

Para que el botón de Google funcione, Google pide un ID de cliente (es lo que usa cualquier web con «Acceder con Google»). Se crea una sola vez, gratis:

  1. 1Entra a console.cloud.google.com, crea un proyecto y habilita la Google Drive API en «APIs y servicios → Biblioteca».
  2. 2En «Pantalla de consentimiento OAuth» elige Externo y añádete como usuario de prueba. Luego en «Credenciales → Crear credencial → ID de cliente OAuth» elige Aplicación web y agrega el origen http://localhost:8000.
  3. 3Copia el ID de cliente (termina en .apps.googleusercontent.com) y pégalo aquí:

🔒 Al acceder, Google te pedirá tu correo y permiso para guardar un archivo privado AnimeList.json en tu propio Drive. La app solo puede ver ese archivo, nada más de tu cuenta. Sin internet, todo sigue guardándose en el equipo y se sube al volver.
